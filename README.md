# Playwright Agent – Planner, Generator & Healer

This is a small **Playwright Agent** project created to demonstrate how AI-assisted test automation can help with test planning, test generation, and test healing.

The project showcases three key capabilities:

* **Planner** – Analyzes the requirement and helps create a test plan.
* **Generator** – Generates Playwright automation based on the test scenario.
* **Healer** – Helps identify and recover from common automation failures such as changed locators or UI elements.

## Project Overview

For this demonstration, I have implemented **two test cases** using Playwright and TypeScript.

The objective is to keep the implementation simple and demonstrate how Playwright Agent concepts can be applied to a real-world UI automation scenario.

## Tech Stack

* Playwright
* TypeScript
* Playwright Test
* Playwright Agents – Planner, Generator & Healer
* Git & GitHub

## Test Cases

The project currently contains two sample test cases covering basic application functionality.

The tests demonstrate:

1. Creating test scenarios using the **Planner**
2. Generating automation using the **Generator**
3. Handling locator/test failures using the **Healer**
4. Executing the generated Playwright tests

## Purpose

This project is primarily a **learning and demonstration project** to understand how AI-assisted capabilities can be integrated into modern Playwright automation.

More test scenarios and enhancements can be added in the future.
